Setup Instructions

To use this app, you need to:

  1. Create a custom app in your Shopify admin
  2. Set the App URL to this page's URL
  3. Set the Allowed redirection URL(s) to this page's URL
  4. Copy your Client ID and update the code with it
  5. Install the app in your store

Note: This is a client-side only implementation for demonstration purposes.
